Hedera testnet · x402 · Blocky402

hedera‑x402

A working x402 payment flow on Hedera testnet: a "researcher" agent sells generated research on a per-request basis, three "requester" agents pay it in real HBAR for real work, and every payment settles on-chain through the Blocky402 facilitator. Nothing here is mocked — every transaction on the live dashboard is a real, independently-verifiable Hedera testnet settlement.

View live dashboard → GitHub repo

How a payment happens

requester asks for research → 402 Payment Required → requester signs a Hedera transfer → Blocky402 verifies + settles → researcher delivers the work

This is the exact scheme of the x402 protocol on Hedera: the requester's Hedera transfer transaction is signed but left partially unsigned (no fee-payer signature); Blocky402 adds its own signature and submits it, paying the network fee and sponsoring settlement. See the repo README for the full protocol trace and a real settled transaction id.

Four agents

Base — the seller

Researcher

The resource server itself. Gates two deliverables behind x402 payment and generates each one for real on request — it doesn't serve canned responses.

Requester

Term-paper reviewer

Pays for feedback on a paper excerpt: strengths, weaknesses, one concrete next revision step.

Requester

News analyst A

Pays for a balanced analysis of a rotating news topic.

Requester

News analyst B

Same deliverable, different topic rotation — running independently so the dashboard shows genuinely concurrent, independent paying agents.

All three requesters currently share one funded Hedera testnet account (a second real paying agent needs a second funded account — a manual faucet step). Each payment is still an independent, real settled transaction.

What's real, what's not

Real: every Hedera testnet transaction, every HBAR transfer, every Blocky402 verify/settle call, every Groq-generated piece of feedback or analysis.
Not real-time: the news analyst's output is a generated analysis from a language model, not a live news feed — it says so in its own output.
